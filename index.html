About Me

From volunteering to vulnerability testing

I like figuring out how things work, and then figuring out how they could go wrong. That habit is what pulled me into security.

I grew up in the Phoenix area. In high school, I served as Vice President of the Phoenix Jewel of the East Lions Club for over three years. I helped organize community service events that added up to more than 450 volunteer hours, and I partnered with four local organizations to set them up. That role taught me how to plan, how to get people to show up, and how to follow through. Those skills matter in engineering just as much as in a service club.

I started college at Arizona State University studying Computer Science with a focus on cybersecurity. I earned a 3.8 GPA there and studied for and passed the CompTIA Security+ exam, along with the Google Cybersecurity Professional Certificate. The more I learned, the more I wanted to understand the full stack, from the logic gates inside a chip up to the cloud services running on top of it. Security problems can show up at any of those layers. That's why I transferred to Georgia Tech for Computer Engineering in Fall 2026.

Alongside school, I've done three internships. At GradAchiever, I wrote Python automation scripts and tested plugin updates. At The Commons XR, I set up and documented Google Cloud networks. Most recently, at Numberz.ai, I worked as an AI Security Engineering Intern. I built a library of attacks to test an AI system that turns plain-English questions into database queries, and I found and reported two real security issues. That was the first time I saw my work protect a real product, and it made me sure this is the field I want.

Things I've built

These are my main technical projects, mostly security tools. I'll keep adding to this page as I finish new work at Georgia Tech.

Continuous LLM Security Red-Teaming Platform

Python · FastAPI · OWASP LLM Top 10

An open-source tool that attacks AI chat models on purpose, so teams can find security problems before attackers do. It grew out of my red-teaming work at Numberz.ai.

  • Covers 5 types of attacks: direct and indirect prompt injection, jailbreaks, system-prompt extraction, and data exfiltration.
  • Counts a finding only when two separate checks agree, an LLM "judge" and a fixed rule-based check. This cuts down false alarms compared to simple keyword matching.
  • Includes a deliberately vulnerable practice app to test against, with hidden "canary" tokens that prove when an attack worked.
  • Runs in GitHub Actions and fails the build if a model gets less safe.

Secure CI/CD Pipeline

GitHub Actions · Terraform · AWS · Docker · OPA/Rego

A build pipeline that checks code for security problems automatically before it can be deployed.

  • Five security gates scan for leaked secrets, unsafe code, vulnerable libraries, risky cloud settings and container issues.
  • Uses short-lived OIDC credentials instead of stored AWS keys, with encryption and audit logging turned on.
  • Eight custom OPA/Rego policies block things like public S3 buckets and wildcard IAM permissions.

Web Application Vulnerability Scanner

Python · aiohttp · asyncio · BeautifulSoup

A fast scanner that crawls a website and tests it for common attacks like SQL injection, cross-site scripting (XSS), broken access control (IDOR) and weak logins. I tested it against practice targets built to be hacked, DVWA and OWASP Juice Shop. It double-checks each result to avoid false alarms, then ranks findings by severity.

AWS IAM Misconfiguration Scanner

Python · Boto3 · Flask · AWS IAM

A tool that reviews AWS accounts for risky permission settings: roles with too much access, unused users and missing multi-factor authentication. It checks for 8 known ways an attacker could raise their own privileges, and shows the results in a simple web dashboard sorted by severity.

Dockerized Security Audit Tool

Python · Docker · Syft · Bandit · Gitleaks · NVD API

Built during my Numberz.ai internship. One command runs four checks on a codebase (a software parts list, a code scan, a secret scan, and a lookup of known vulnerabilities) and combines them into a single report.

More code is on my GitHub.
